# TripSquad: trip planning that takes action
Tell me where you want to go and I build a **weather-aware, budgeted, day-by-day itinerary**, then give you **Google Calendar events** and **Google Maps routes** for every day.

**Try asking**
- Plan a 3-day trip to Jaipur from Delhi next weekend under ₹15,000
- Weekend in Goa from Pune
- 4 days in Kyoto from Mumbai, budget $1500

**How it works:** I coordinate a Weather agent (live forecast), a Places agent (attractions) and a Budget agent (cost + FX) in parallel, then adapt the plan: rain ⇒ indoor spots, heat ⇒ shaded midday. Say "make it 4 days" or "under ₹10,000" to refine.

Supports the Agent Chat Protocol and ASI:One Interactive Cards (form + review).
